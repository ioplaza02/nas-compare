# NAS 他社比較ツール（社内営業用）

I-O DATA の LAN DISK と他社NASを比較し、お客様提案前の下調べ時間を短縮するための社内ツールです。

## 画面
1. **I-O DATA商品一覧** … 絞り込み＋「他社の近い機種を探す」ボタン
2. **I-O DATA → 他社** … I-O DATAの型番（シリーズ or 容量別型番）を入れ、メーカーを選んで実行 → 各社上位3件
3. **他社型番 → I-O DATA** … 他社の型番を自由入力して実行 → I-O DATAの候補上位4件

各候補には「一致度」「比較表（違う行は黄色）」「共通点／違い／営業メモ」と、両社の出典リンクを表示します。

## データ
| ファイル | 内容 |
|---|---|
| `../nas-selector/data/products.json` | I-O DATAのデータ（NASセレクターが毎日自動更新したものを直接読み込み） |
| `data/iodata-products.json` | 上が読めない時の予備コピー |
| `data/buffalo-products.json` | バッファローのデータ（公式サイトの仕様表から取得） |

## バッファローのデータ更新
```
node scripts/scrape-buffalo.mjs
```
- 1件ずつ2秒間隔でアクセスします（約35シリーズで2〜3分）
- 取れなかった項目は前回の値を引き継ぎます
- 正常に読めたシリーズが8割未満などの場合は、本番ファイルを上書きせず `data/buffalo-products.failed.json` に保存して終了します
- 調査用にHTMLも保存したい場合は `--save-html`（`debug/` フォルダに保存）

## 一致度の計算（目安）
OS系統30 ／ Windowsエディション5 ／ ベイ数25 ／ 設置形態15 ／ LAN速度15 ／ 容量10 ／ 現行品5（100点満点に換算）
